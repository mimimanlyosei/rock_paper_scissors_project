# Rock, Paper, Scissors 🎮🪨📄✂️

This was my second Python project, created as part of Module 2 in the Mimo Python Developer course.  
It's a two-out-of-three Rock, Paper, Scissors game where you play against the computer!

## 👾 How It Works

- You and the computer each choose rock, paper, or scissors.
- The first to win 2 rounds takes the game.
- The computer’s moves are randomized, making each round unpredictable.
- After each round, the current score is displayed to keep the tension high 😄

## 🧠 What I Learned

- How to use `while` loops for continuous play
- How to use `random.choice()` to simulate unpredictability
- How to apply conditional logic to determine the winner
- How to track state using variables across loop iterations
- Practicing lowercase normalization for consistent input handling

## 🛠 Technologies

- Python 3
- Terminal
